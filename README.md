# Primer

A modern UI frontend for [KOReader](https://github.com/koreader/koreader): a curated, Kindle-inspired interface (library, reading toolbar, quick panel, Aa, dictionary, notes, settings) over KOReader's engine. It's a KOReader plugin plus a few user patches, so it runs wherever KOReader does, and adapts to what each device can do.

The name: a first book; the interactive book in Neal Stephenson's *The Diamond Age*; and a quiet nod to Amazon (Prime → Primer).

See [CHANGES.md](CHANGES.md) for what's done and planned.

## Devices

Primer is developed and tested on these, all with KOReader v2026.07.1:

| Device | Firmware and setup | How Primer gets there |
|---|---|---|
| Kindle Voyage | 5.13.6, jailbroken, KUAL, KOReader `kindlepw2` build | USB drive: `tools/deploy.sh` |
| Kindle Paperwhite (12th gen, 2024) | 5.19.6, jailbroken with Véra, KOReader installed with KPM (`kindlehf`) | MTP: `tools/deploy-mtp.sh` |
| reMarkable Paper Pro Move | Developer mode, KOReader through AppLoad (XOVI) | SSH over USB: `tools/deploy-remarkable.sh` |

Other KOReader devices (other Kindles, Kobo, PocketBook…) should work: device-specific features check for what's there and hide or fall back otherwise. Layouts scale from the screen's size but are only tuned on the devices above.

| Fonts | Amazon Ember, Bookerly, Caecilia (built in) | same | Inter, Literata, Bitter (bundled) | bundled |
| Book text | Aa sizes as tuned | 10% smaller (7" screen) | as tuned, heavier and higher contrast | as tuned |
| Start from the home screen | KUAL > KOReader | "Primer" on the home screen (`Primer.sh`, through KPM) | AppLoad | KOReader's own launcher |
| Start at boot | Upstart job, Kindle framework stopped while Primer runs | Upstart job, Primer runs over the framework (`--asap`), which is what lets the Kindle come back on exit on 5.16.3+ | — | — |
| Connect to a computer | Asks, closes Primer, lends the drive, comes back on eject | Asks, closes Primer for MTP file transfer, comes back on unplug | — | — |
| Page turn animation | — | The display's own page sweep, as on the stock Kindle (light mode; the stock reader doesn't sweep in dark mode either) | — | Where KOReader supports it |
| Sleep screens | The Kindle's own illustrations, or Primer's collections | same | Primer's collections | Primer's collections |
| Turn for landscape | — | — | Accelerometer: two pages side by side | — |

## What's here

| `src/plugins/voyagepanel.koplugin/defaults/` | Primer's default settings (look, footer, reading, gestures), applied on first run |

| `src/extensions/primer/` | Kindle start-at-boot job (once per boot, `/mnt/us/NO_KOREADER` skips it) and the KUAL menu for it. Primer's Settings and welcome screen use the same script, and Primer refreshes the installed job when it changes |

## Install (users)

**Step-by-step guide: [INSTALL.txt](INSTALL.txt)**, with one guide per device. Download the zip from [Releases](https://github.com/skuthus/Primer/releases). In short: get KOReader running on the device (on a Kindle that means a jailbreak first), copy the release zip's folders over it, and start KOReader. Primer sets itself up on first start (defaults, gestures, no quickstart guide) and, on a Kindle, offers to start at boot.

## Release

```sh
tools/package.sh                                   # dist/Primer-<version>.zip
tools/package.sh --koreader koreader-kindlepw2-….zip   # …-with-KOReader.zip, KOReader included
```

For a with-KOReader zip, pick the KOReader build for the target: `kindlepw2` for Kindles before firmware 5.16.3, `kindlehf` for 5.16.3 and newer. On 5.16.3+ the plain zip is the usual choice, since KOReader comes from KPM there.

A StarDict dictionary folder placed in `vendor/dict/` (git-ignored) is included in `koreader/data/dict/`. The version is in `VERSION`.

## Deploy (development)

### Kindle as a USB drive (Voyage)

Exit KOReader on the Kindle (so USB drive mode is available), plug in, then:

```sh
tools/deploy.sh /path/to/Kindle     # defaults to /Volumes/Kindle
```

Restart KOReader to load the changes. Errors land in `koreader/crash.log` on the device.

### Kindle over MTP (Paperwhite 12)

Newer Kindles don't mount as a drive; they speak MTP, which works while Primer is running. Plug in, then:

```sh
tools/deploy-mtp.sh                 # the first Kindle gio sees, or pass its mtp:// storage URI
```

It copies file by file with `gio`, also putting `Primer.sh` in `documents/`. Restart KOReader to load the changes. `koreader/crash.log` is buffered and loses its tail when KOReader is killed (plugging in can do that), so for diagnostics write to your own file and flush each line.

### reMarkable Paper Pro Move

The reMarkable doesn't mount as a drive; Primer goes over SSH on its USB network (`10.11.99.1`). KOReader is installed through AppLoad (XOVI), at `/home/root/xovi/exthome/appload/koreader`.

One-time setup:

1. Turn on developer mode on the reMarkable (Settings > General > Software > Advanced; it factory-resets the device).
2. Make a key and an SSH host entry named `remarkable`:
   ```sh
   ssh-keygen -t ed25519 -f ~/.ssh/remarkable -N ""
   ```
   and in `~/.ssh/config`:
   ```
   Host remarkable
       HostName 10.11.99.1
       User root
       IdentityFile ~/.ssh/remarkable
       IdentitiesOnly yes
   ```
3. With the device plugged in, authorize the key (the root password is under Settings > General > Help > About > Copyrights and licenses):
   ```sh
   ssh-copy-id -i ~/.ssh/remarkable.pub root@10.11.99.1
   ```

Each deploy (device awake and plugged in):

```sh
tools/deploy-remarkable.sh
```

It lints, finds KOReader on the device, backs up KOReader's settings once (`settings.reader.lua.pre-primer`), and copies the plugin, patches, fonts and sleep screens. Then restart KOReader: AppLoad leaves it running after Exit, so stop it first, then tap KOReader in AppLoad.

```sh
ssh remarkable 'for p in $(ps | grep "[r]eader.lua" | awk "{print \$1}"); do kill -TERM $p; done'
```

KOReader can't be started over SSH (AppLoad gives it its window). Errors land in `crash.log` in KOReader's folder on the device. Keep the reMarkable's own orientation lock on while reading, or the system rotates KOReader's window as well as Primer's "Turn for landscape" (Settings > Screen and brightness).

## Dictionary

Primer expects a StarDict dictionary in `koreader/data/dict/` (in KOReader's folder on the device). We use the English-English Wiktionary from [Vuizur/Wiktionary-Dictionaries](https://github.com/Vuizur/Wiktionary-Dictionaries) (`English-English Wiktionary dictionary stardict.tar.gz`, CC BY-SA); unpack it and copy its folder there. It isn't committed here (30 MB).

## Fonts

On Kindles, Primer uses the device's built-in Amazon Ember (interface), Bookerly (reading) and Caecilia (library titles), and the Aa panel lists the Kindle's fonts plus any in the Kindle's `fonts/` folder. Those are Amazon's proprietary fonts and aren't bundled. Everywhere else it uses the open fonts in `src/fonts/` (installed to `koreader/fonts/primer/`): Inter for the interface, Literata for reading, Bitter for library titles, each under the SIL Open Font License (licenses alongside). `fonts.lua` picks per role: Kindle font, else bundled, else KOReader's default.

## Notes

- Never use `_` as a throwaway variable in plugin code: KOReader's gettext is `_`, and shadowing it breaks `_("…")` calls. The lint enforces this.
- Books for Primer go on a Kindle as EPUB (or MOBI, PDF…). KOReader can't render AZW3: its engine reads only the old MOBI part of a Mobipocket file, and an AZW3 is all KF8.
- Device checks go through KOReader's `Device` (`isKindle()`, `isMTK()`, `canDoSwipeAnimation()`, `hasLightSensor()`…), never through a model name, except where a model really differs (the Paperwhite 12's text scale in `fonts.lua`).
